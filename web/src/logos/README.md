# Service logos

GitHub, Render, Cloudflare, Supabase, Resend, DigitalOcean, Vercel, Netlify, Fly.io, Railway, Sentry, Stripe, Paddle, GitLab, AWS, MongoDB, SendGrid, Google Analytics, Clerk and OpenAI marks from [Simple Icons](https://simpleicons.org)
13.21.0, released under CC0 1.0 (public domain). Each is the trademark of its
owner and is used only to show which account a service is.

The Search Console mark (search-console.svg) isn't Google's logo: it's a plain
magnifier drawn for Periskopos, so the account has a mark of its own.

The Neon mark (neon.svg) isn't Neon's logo, which Simple Icons doesn't carry:
it's a plain N drawn for Periskopos.
